## 代码、测试与本地数据

- `apps/server`：后端源码、数据库建表及种子数据脚本。
- `apps/web`：前端源码。
- `tests/acceptance`：V1.2 验收脚本及历史证据。
- `data`：本地运行数据库；依赖、构建产物和 `.tmp` 不提交 Git。

目录整理不改变启动方式，具体步骤见 Demo 启动说明。
