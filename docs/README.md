## 代码、测试与本地数据

- `apps/server`：后端源码及数据库建表、种子数据脚本。
- `apps/web`：前端源码，演示模式使用构建产物。
- `tests/acceptance`：验收脚本与提交的结果证据，位置不变。
- `data`：本地运行数据库；`node_modules`、`.npm-cache`、`.tmp`及各应用的`dist`为本地依赖或生成内容，不提交Git。

此次目录整理不改变启动方式：在仓库根目录执行`npm ci`、`npm run build`、`npm start`。
