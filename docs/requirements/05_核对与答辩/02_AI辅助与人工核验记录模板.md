## 建议核验问题

1. 登录是否被不必要地包含进所有用例？
2. 同一房间重叠预约的多重性和时间约束是否同时表达？
3. 预约取消后是否错误地创建入住或收款记录？
4. 提醒是否每次扫描都重复生成？
5. 结单失败后是否错误释放房间？
